# Agentic Story Studio

[Permalink: Agentic Story Studio](https://github.com/Senseiglobal/agentic-story-studio#agentic-story-studio)

An agentic cinematic storytelling studio that transforms complex ideas into evidence-grounded visual stories using Gemini, Google Cloud, and Parallel.

Built for the Google Cloud Agentic Cinema hackathon.

## Architecture

[Permalink: Architecture](https://github.com/Senseiglobal/agentic-story-studio#architecture)

1. **Research Director**(Implemented, Live-generation validated)

   - Researches complex topics using Parallel Search.
2. **Evidence Editor**(Implemented, Live-generation validated)

   - Evaluates research evidence and classifies claims (ESTABLISHED\_SCIENCE, SCIENTIFIC\_HYPOTHESIS, etc.).
3. **Story Director**(Implemented, Live-generation validated)

   - Translates validated research into cinematic possibilities while maintaining strict fact/fiction boundaries.
4. **Cinematic Director**(Implemented, Live-generation validated)

   - Translates narrative briefs into visually coherent cinematic plans (sequences, scenes, shots).
5. **Image Generation Director**(Implemented, Live-generation validated)

   - Converts shot plans into detailed image generation specifications.
   - Storyboard generation powered by Gemini-2.5-Flash-Image.
6. **Video Generation Director**(Implemented, Dry-run validated)

   - Translates cinematic plans and storyboards into structured Video Generation Plans.
7. **Veo Adapter**(Implemented, Dry-run validated)

   - Handles asynchronous video generation using Google's Veo 3.1 model.
   - _Note: Runtime availability depends on Google Cloud project/model access._

## Pipeline Workflow

[Permalink: Pipeline Workflow](https://github.com/Senseiglobal/agentic-story-studio#pipeline-workflow)

Research Question
→ Parallel Search
→ Evidence Editor
→ Claim Ledger
→ Story Director
→ Cinematic Story Brief
→ Cinematic Director
→ Scene/Shot Plan
→ Image Generation Planner
→ Storyboard Images
→ Video Generation Planner
→ Veo Video Generation (Dry-run validated)

### Environment

[Permalink: Environment](https://github.com/Senseiglobal/agentic-story-studio#environment)

- Python 3.12
- Google ADK (Agent Development Kit)
- Vertex AI (Gemini, Imagen, Veo)
- Parallel Web Search

### Verification Scripts

[Permalink: Verification Scripts](https://github.com/Senseiglobal/agentic-story-studio#verification-scripts)

- `scripts/test_evidence_pipeline.py`: Validates Research and Evidence stages.
- `scripts/test_story_pipeline.py`: Validates Story generation.
- `scripts/test_cinematic_pipeline.py`: Validates Cinematic planning and ProjectState persistence.
- `scripts/test_image_generation_pipeline.py`: Validates Storyboard generation (supports DRY-RUN).
- `scripts/test_video_generation_pipeline.py`: Validates Video planning and Veo orchestration (DRY-RUN).
